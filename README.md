# emailscraper.py
العربية: أداة استخراج البريد الإلكتروني هي أداة مبنية باستخدام لغة Python، تتيح للمستخدم إدخال اسم النطاق (Domain) الخاص بموقع إلكتروني، ثم تبحث تلقائيًا عن عناوين البريد الإلكتروني المرتبطة بهذا النطاق وتعرض العناوين التي تعثر عليها، مما يسهل الوصول إلى معلومات التواصل الخاصة بالموقع.
