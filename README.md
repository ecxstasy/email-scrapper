# emailscraper.py
Το εργαλείο εξαγωγής email είναι μια εφαρμογή γραμμένη σε Python που επιτρέπει στον χρήστη να εισάγει το όνομα τομέα (domain) ενός ιστότοπου, στη συνέχεια αναζητά αυτόματα διευθύνσεις email που συνδέονται με αυτόν τον τομέα και εμφανίζει τις διευθύνσεις που εντοπίζει, διευκολύνοντας την πρόσβαση στα στοιχεία επικοινωνίας του ιστότοπου.
# Usage:
python3 emailscraper.py<br>
enter urls: (url)<br>
ex: enter urls: https://pornhub.com
